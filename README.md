# Snake Game 🐍

A classic Snake Game built from scratch using **C programming**. This is my first personal project in C, created to strengthen my understanding of programming fundamentals, logic building, and game development concepts.

## Features

* Control the snake using keyboard inputs
* Snake grows after eating food
* Score tracking
* Game-over condition when the snake collides with itself
* Boundary collision handling
* Simple console-based gameplay

## Tech Stack

* **Language:** C
* **Concepts:** Arrays, loops, functions, conditional statements, keyboard input, game logic
* **Development:** VS Code

## What I Learned

Through this project, I practiced:

* Breaking a problem into smaller functions
* Working with arrays and coordinates
* Handling keyboard input
* Implementing collision detection
* Managing game state and score
* Building logical problem-solving skills using C
